# ROYSONS TRUST — Official Web Platform

Welcome to the official web repository for **ROYSONS TRUST**, a premier charitable and community-focused humanitarian organization dedicated to empowering vulnerable communities through education, clinical healthcare, clean water security, and social welfare across Pakistan.

---

## 🌟 Key Features

* **Complete App Architecture**: 23+ pages built on Next.js App Router (Programs, Projects, Impact Dashboard, Stories, Transparency & Audits, Donation Portal, Volunteer Recruitment, Leadership, Certifications).
* **Official Visual Identity**: Incorporates official brand colors (Deep Navy `#042E3A` and Signature Teal `#00A99D`), Times New Roman typography, and authentic community imagery.
* **Interactive Experience**:
  * Viewport-triggered animated counters on key impact metrics.
  * IntersectionObserver-driven scroll reveal animations across all sections.
  * Tactile card hover states with smooth image zooms, glowing borders, and elevation shadows.
* **Direct Welfare & Transparent Giving**:
  * Interactive donation pledge flow with verified Raast, IBAN, and mobile wallet details.
  * 100% audited financial disclosures and zero administrative cuts on Zakat pledges.
* **Performance & SEO**: Fully responsive, mobile-first, and optimized for fast production builds with Turbopack.

---

## 🛠️ Tech Stack

* **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
* **Library**: [React 19](https://react.dev/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Animations**: [Framer Motion](https://www.framer.com/motion/) & Custom CSS Transitions

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
